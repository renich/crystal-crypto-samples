# Crystal Crypto Samples

Sample integration application for the EVALinux Crypto Suite.

## Features
Demonstrates the functionality of:
- CBOR FIDO Encoding/Decoding
- ECC Constant Time Signatures (libsodium)
- DBus Native Integrations
- TPM2 TSS Hardware Keys
