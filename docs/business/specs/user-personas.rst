=============
User Personas
=============

Target Audience
---------------

Security & Authentication Engineers
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Engineers building FIDO2/WebAuthn authenticators, passkey managers, or zero-trust agents in Crystal who need a working reference demonstrating how CBOR, classical ECC, post-quantum lattice cryptography, D-Bus IPC, and TPM 2.0 fit together.

Linux Distribution & Packaging Maintainers
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Maintainers validating that the complete EVALinux Crypto Suite builds and passes runtime smoke tests against system ``openssl`` and ``libsodium`` packages.
