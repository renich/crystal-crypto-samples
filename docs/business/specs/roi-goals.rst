=========
ROI Goals
=========

Strategic Objectives
--------------------

#. **Zero Cross-Shard Linker Conflicts**: Continuously verify that ``crystal-cbor-fido``, ``crystal-ecc-constant``, ``crystal-pqc-constant``, ``crystal-dbus-native``, and ``crystal-tpm2-tss`` compile and link cleanly inside a single Crystal binary on both Fedora and Alpine Linux.
#. **Executable Documentation**: Provide copy-pasteable, deterministic code samples for every shard in the suite, including Post-Quantum Cryptography (``ML-KEM-768`` and ``ML-DSA-65``).
#. **Automated CI Gatekeeper**: Catch cross-repository API drift immediately via automated CI pipelines.
